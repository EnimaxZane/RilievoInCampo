# Rilievo in Campo

Web app installabile (PWA) per rilievi in campo su planimetria: arredi, impianti idrotermosanitari ed elettrici, quote, note e foto, con esportazione in PDF. Funziona offline dopo la prima apertura.

Aprire l'indirizzo GitHub Pages con Chrome su Android e scegliere "Aggiungi a schermata Home".
